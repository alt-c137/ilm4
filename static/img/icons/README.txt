СВОИ ИКОНКИ РАЗДЕЛОВ — без правки кода
=======================================

Положи в эту папку файл с именем раздела:

  prayer.svg     — Время намаза
  buy.svg        — Купля-продажа (ilmbuy)
  map.svg        — Карта
  health.svg     — Здоровье
  nikah.svg      — Никах
  forum.svg      — Форум
  news.svg       — Новости
  jobs.svg       — Работа
  migration.svg  — Миграция
  services.svg   — Услуги
  library.svg    — Библиотека
  chat.svg       — Чат
  wallet.svg     — Кошелёк

Формат: SVG (лучше) или PNG. Рекомендуемый размер SVG — 24×24 viewBox,
PNG — квадрат от 96×96. Иконка показывается в белом цвете на цветной
плашке раздела, так что бери монохромный контур (stroke="currentColor"
не сработает в <img>, крась сразу в #ffffff).

Пример уже лежит рядом: prayer.svg (полумесяц).
