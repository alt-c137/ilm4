# Что подключить вручную: где взять, куда вписать

Всё, что требует регистрации, ключа или настройки у внешнего сервиса. Порядок — от важного к
желательному. Ключи вписываются в файл **`.env`** (на ПК — в папке проекта, на сервере — в папке
`ilm4`), настройки-галочки — в **админке → «Настройки сайта»**.

После правки `.env`: на ПК перезапустить `bash scripts/run_local.sh`, на сервере —
`docker compose -f docker-compose.prod.yml up -d`.

> Как запустить сам сайт (ПК и сервер) — в `КАК_ЗАПУСТИТЬ.md`. Этот файл — только подключения.

## 1. Домен ilm4.com — где он прописывается

Домен вписывается **в нескольких местах**. Если адрес другой (например `ilm4.uz`), меняйте везде.

**а) Регистратор → Cloudflare**
1. Зарегистрируйтесь на cloudflare.com → Add a site → `ilm4.com` → тариф Free.
2. Cloudflare покажет два адреса NS-серверов. У регистратора домена (где покупали) замените NS на них.
3. Cloudflare → DNS → добавьте записи:
   - `A` · имя `@` · IP вашего сервера · Proxied (оранжевое облако);
   - `A` · имя `www` · тот же IP · Proxied.
4. Cloudflare → SSL/TLS → режим **Flexible** (позже можно Full с сертификатом на сервере).

**б) `.env` на сервере**
```
ALLOWED_HOSTS=ilm4.com,www.ilm4.com
CSRF_TRUSTED_ORIGINS=https://ilm4.com,https://www.ilm4.com
SITE_URL=https://ilm4.com
DEFAULT_FROM_EMAIL=ilm4 <noreply@ilm4.com>
SECURE_SSL=True
```

**в) Внешние сервисы, где указывается адрес** (подробности — в разделах ниже):

| Где | Что вписать |
|---|---|
| Telegram-бот (кнопка «Никях», вебхук) | ставится сам при старте сервера из `SITE_URL` |
| Cloudflare Turnstile | домен `ilm4.com` |
| MapTiler | разрешённый адрес `https://ilm4.com/*` |
| Google OAuth | `https://ilm4.com/accounts/google/callback/` |
| Click | `https://ilm4.com/payments/click/prepare/` и `…/complete/` |
| Stripe | `https://ilm4.com/payments/stripe/webhook/` |
| Brevo (почта) | подтверждение домена отправителя (DNS-записи в Cloudflare) |
| Мобильное приложение | `mobile/app.json` → `extra.apiUrl` и `mobile/eas.json` → `EXPO_PUBLIC_API_URL` (уже `https://ilm4.com`) |

## 2. Telegram-бот и группа модераторов — **основа**

Через бота работают:
- никях как мини-приложение;
- уведомления людям;
- **жалобы и проверка анкет**: они приходят в группу модераторов с кнопками «✅ Одобрить / ❌ Отклонить»;
- верификация видео-кружком;
- **подтверждение номера телефона** (бесплатно, без SMS): человек нажимает в боте «📱 Отправить мой номер». Без подтверждённого номера нельзя подавать объявления и заходить в никях — один номер = один аккаунт, боты не спамят, а лимит анкет не обойти новым аккаунтом. Пока бот не подключён, проверка номера не включается;
- сводки ИИ-модерации;
- оплата звёздами.

1. **Бот.** Telegram → @BotFather → `/newbot` → имя (например «ilm4 Никях») → логин (например `ilm4_nikah_bot`).
   BotFather пришлёт токен. В `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456789:AA...
   TELEGRAM_BOT_USERNAME=ilm4_nikah_bot
   ```
2. **Оформление бота** (в @BotFather):
   - `/setuserpic` — аватар (можно `static/img/app/icon-512.png`);
   - `/setdescription` — «Никях ilm4 — знакомство для брака по Корану и Сунне».
3. **Группа модераторов.**
   1. Создайте в Telegram группу (например «ilm4 модерация»), добавьте туда бота и всех модераторов.
   2. Запустите сайт (на ПК: `bash scripts/run_local.sh`) и напишите в группе `/id`. Бот ответит числом вида `-1001234567890`.
   3. Впишите его в `.env`:
      ```
      TELEGRAM_MODERATION_CHAT_ID=-1001234567890
      ```
   4. Кто может нажимать «Одобрить». Каждый модератор пишет боту в личку `/id` и получает свой номер. Номера — через запятую:
      ```
      TELEGRAM_MODERATOR_IDS=11111111,22222222
      ```
      Пусто — одобрять может любой участник группы.
4. **Только сервер:** секрет вебхука — любая длинная строка:
   ```
   TELEGRAM_WEBHOOK_SECRET=придумайте-длинную-случайную-строку
   ```
   При старте сервера бот сам настроит кнопку «Никях» и вебхук. На ПК вебхук не нужен — скрипт запускает бота опросом.

**Что приходит в группу модераторов:**
- 📝 новые и изменённые анкеты никяха (с фото под «спойлером») — кнопки «Одобрить / Отклонить»;
- 🎥 видео-кружки верификации — кнопки «Лицо видно / Отклонить»;
- 🚩 жалобы на публикации, анкеты и людей;
- 🤖 вердикты ИИ-модерации.

## 3. Капча — Cloudflare Turnstile
Защищает регистрацию, «забыли пароль» и вход после 3 ошибок. Без картинок-головоломок, работает в Telegram.
1. dash.cloudflare.com → **Turnstile** → Add widget.
2. Name: `ilm4`. Hostname: `ilm4.com` (для теста на ПК можно добавить `trycloudflare.com`). Режим: **Managed**.
3. В `.env`:
   ```
   TURNSTILE_SITE_KEY=0x4AAAA...
   TURNSTILE_SECRET_KEY=0x4AAAA...
   ```
Без ключей капча выключена.

## 4. Почта — Brevo
1. brevo.com → регистрация → **Senders, Domains** → добавить домен `ilm4.com` → Brevo покажет
   DNS-записи (SPF, DKIM) → добавить их в Cloudflare → DNS. Без этого письма попадают в спам.
2. **SMTP & API** → SMTP → **Generate a new SMTP key**.
3. В `.env` (логин — email аккаунта Brevo; если в ключе есть `@` или `/`, замените: `@` → `%40`, `/` → `%2F`):
   ```
   EMAIL_URL=smtp+tls://ваш_логин%40gmail.com:КЛЮЧ@smtp-relay.brevo.com:587
   DEFAULT_FROM_EMAIL=ilm4 <noreply@ilm4.com>
   ```

## 5. ИИ-модерация — Claude (Anthropic)
ИИ проверяет каждую новую публикацию и анкету на харам, мошенничество, спам, оскорбления, контакты в
анкетах и возраст. Вердикт видно в админке («Проверки ИИ», колонка «ИИ» у анкет), сводка приходит
в группу модераторов.
1. console.anthropic.com → регистрация → **Billing** → пополнить (5–10 $ хватит надолго).
2. **API Keys** → Create Key → в `.env`:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
3. Админка → «Настройки сайта»:
   - «ИИ-модерация включена» — да;
   - «ИИ одобряет чистые публикации сам» — выключено (ИИ только подсказывает), включите, когда убедитесь, что вердикты точные;
   - «ИИ проверяет фото анкет никяха» — выключено. Фото уходит во внешний сервис; включайте, только если это прописано в политике конфиденциальности.

Альтернатива без оплаты: `OPENAI_API_KEY` с platform.openai.com. Это бесплатная модерация OpenAI, но она ловит только грубое (18+, насилие, ненависть), а мошенничество и контакты не видит.

**Бесплатно и без ключей всегда работает:**
- телефоны, ники и ссылки в анкетах никяха отклоняются;
- в чате никяха такие сообщения не отправляются (галочка «никях: блокировать контакты в чате»).

## 6. Карта — MapTiler
1. cloud.maptiler.com → регистрация → **API keys** → скопировать ключ.
2. В настройках ключа → **Allowed HTTP origins**: `https://ilm4.com/*` (и адрес туннеля для теста).
3. Админка → «Настройки сайта» → **«карта: ключ MapTiler»**.
Без ключа карта работает на OpenStreetMap/Esri. Для большого коммерческого трафика нужен платный тариф MapTiler.

## 7–10. Оплата
Подробные шаги — в `КАК_ЗАПУСТИТЬ.md`, раздел 3. Кратко:

| Способ | Что сделать | Адреса у провайдера |

| **NOWPayments** | регистрация, кошелёк для выплат; `NOWPAYMENTS_API_KEY`, IPN secret → `NOWPAYMENTS_IPN_SECRET` | передаётся сам |

**Первый платёж каждым способом — на маленькую сумму.**

## 11. Вход через Google
console.cloud.google.com:
1. Создайте проект.
2. **APIs & Services → OAuth consent screen**: External, название ilm4, email поддержки.
3. **Credentials → Create credentials → OAuth client ID**: тип Web application.
4. Authorized redirect URIs: `https://ilm4.com/accounts/google/callback/`.
5. Client ID и Secret → в `.env`:
   ```
   GOOGLE_OAUTH_CLIENT_ID=...apps.googleusercontent.com
   GOOGLE_OAUTH_CLIENT_SECRET=...
   ```
Кнопка «Войти через Google» появляется на сайте **только после** того, как ключи вписаны (раньше она была видна и без ключей и просто возвращала на страницу входа).

## 12. Звонки через мобильный интернет — TURN
metered.ca → Open Relay / TURN server → получить адрес, логин, пароль → админка → «Настройки сайта» →
«звонки: TURN-сервер / логин / пароль». Без TURN часть звонков через мобильный интернет не соединится.

## 13. Мобильное приложение (Android и iOS)
Полноценное приложение (React Native / Expo) в папке `mobile/`. Подробно — `mobile/README.md`. Коротко:

1. **Посмотреть на телефоне сейчас, бесплатно:** телефон → приложение **Expo Go**; на ПК —
   `bash scripts/app_setup.sh` (один раз), затем `bash scripts/run_local.sh` и во втором окне
   `bash scripts/run_app.sh` → отсканировать QR-код.
2. **Аккаунт для сборки:** **expo.dev** → Sign up → в папке `mobile`: `npx eas-cli@latest login`,
   `npx eas-cli@latest init` (впишет `projectId` в `app.json` — без него не будет пушей).
3. **APK для себя / тестеров:** `npm run build:apk` (сборка в облаке, ссылка придёт через 10–20 минут).
4. **Пуши на Android:** console.firebase.google.com → создать проект → добавить Android-приложение
   с пакетом `com.ilm4.app` → Project settings → Service accounts → «Generate new private key» (JSON) →
   `npx eas-cli@latest credentials` → Android → production → **FCM V1** → загрузить этот JSON.
   На iPhone ключ пушей Expo создаст сам при первой сборке `npm run build:ios`.
   **На сервере для пушей ничего вписывать не нужно** — он шлёт через Expo Push.
5. **Магазины:** Google Play Console (25 $ разово) → `npm run build:android` → `npm run submit:android`;
   App Store (99 $ в год, Mac не нужен) → `npm run build:ios` → `npm run submit:ios`.
6. **В админке:** «приложение: минимальная версия» (заставить старые версии обновиться) и
   «приложение: объявление вверху».

Идентификатор приложения — `com.ilm4.app` (менять нельзя после публикации).

## Галочки в админке (без ключей)
Админка → **«Настройки сайта»**:
- **чат:** фото, **видео**, голосовые, кружки, аудио- и **видеозвонки**, «найти знакомых» — каждое отдельной галочкой, действует и на сайте, и в приложении;
- **никях-чат: фото, видео и кружки** (выкл. по умолчанию — в переписке пары только текст и голос, фото — через защищённый обмен);
- **лента** (`/feed/`);
- **безопасная сделка** (выкл.), **вывод средств** (выкл.);
- **никях:** цена чата, анкет в день, премиум (вкл., цена, дней), «вернуть отклонённых», бонус за приглашение, минут на фото, блокировка контактов в чате;
- **ИИ-модерация:** вкл., автоодобрение, проверка фото;
- **карта:** ключ MapTiler; **Telegram Stars:** курс;
- **звонки:** TURN;
- **приложение:** минимальная версия, объявление вверху;
- **подтверждённый номер — для публикаций** и **— для никяха** (обе вкл.): что требует подтверждения номера через Telegram. Сотрудников не касается.

**Модерация без админки.** Войдите на сайт своим аккаунтом администратора: в меню профиля появится **«Модерация»** (с числом ожидающих) — там анкеты никяха, объявления всех разделов и жалобы, кнопки «Одобрить» / «Отклонить» с причиной (автор получает уведомление). На странице любой публикации и анкеты администратор видит панель «Модератор» с теми же кнопками — даже если она ещё не одобрена.

Разделы целиком (вкл / выкл / «скоро») — админка → **«Разделы»**. Например, **маркетплейс** = раздел «Купля-продажа» (ключ `buy`): «выключен» — пропадает с сайта, из меню, из поиска и из приложения; «скоро» — виден с плашкой «Скоро».
