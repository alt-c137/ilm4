## Коротко: можно ли запускаться

**Сайт — да, можно открывать для первых людей** (закрытая бета: родные, знакомые, одна-две мечети), как только:

1. куплен сервер и домен, сайт поднят по [docs/LAUNCH.md](docs/LAUNCH.md);
2. перевыпущен токен бота (`/revoke` в @BotFather — старый был в переписке);
3. сменены временные пароли (`isa`, аккаунт сына учителя);
4. в «Настройках сайта» выбран аккаунт поддержки;
4а. на сервере проверен конфиг nginx (`nginx -t`) и включён `SECURE_SSL=True` вместе с Cloudflare (v54);
5. ты сам прошёл список «Что проверить руками» ниже — на ПК и на телефоне.

**Приложение в магазины — пока нет.** Его нужно один раз собрать (EAS) и погонять на 2–3 телефонах:
звонки, пуши, сжатие видео, жесты записи голоса работают только в собранном приложении. Через Expo Go
можно смотреть всё остальное уже сейчас.

**Широкий запуск (реклама, тысячи людей)** — после беты: 2–4 недели живых людей покажут ошибки, которые
не видны на тестах. Плюс до этого: оплата (кошелёк/подарки), модераторы на дежурстве, резервные копии на сервере.

## Что проверить руками (по порядку, ~1 час)

Запусти свои окна: `bash scripts/run_local.sh ngrok` и `bash scripts/run_app.sh`.
Нужны **два аккаунта** (второй — в другом браузере или на втором телефоне).

**Чаты**
1. Чаты → «⋮» → «Папки с чатами» → «Создать папку»: название «Семья», добавить 2 чата → вкладка появилась сверху (пока папок нет — вкладок нет, как в Telegram).
2. Долгое нажатие (на ПК — правая кнопка) на чат: закрепить, в архив, пометить непрочитанным, добавить в папку.
3. Со второго аккаунта написать в архивный чат → он сам вернулся из архива.
4. В чате: ответить (на телефоне — свайп сообщения влево), изменить своё, поставить реакцию, закрепить, переслать в два чата и в «Избранное», найти слово через поиск.
5. Начать писать, выйти из чата → в списке «Черновик: …».
6. Пока второй печатает — видно «печатает…».
7. В группе: «Сведения» → медленный режим 10 секунд → второй не может писать чаще.
8. Канал: включить комментарии → под постом «Комментировать».
9. Нажать на аватар человека → листаются фото. Поставить себе новую аватарку → старая осталась в истории.

**Лента**
10. Главная → «Лента» → написать запись с 2 фото → лайк, комментарий, ответ на комментарий.
11. Второй аккаунт: подписаться на первого → его записи в общей ленте. Приватность → «Кто видит мои счётчики» → «Никто» → у второго числа пропали.
12. «Моя история» → фото → второй видит кружок, открывает; первый видит «Кто смотрел».

**Трекер**
13. «Готовые привычки» → «Пять намазов» и «Таблетки» → у таблеток 3 напоминания.
14. «⋯» у привычки → «Пропуск по уважительной причине», «Заметка к этому дню», «Календарь и история».
15. Общий трекер → срок соревнования → «Чат трекера».

**Карта**: открыть, отдалить (метки собираются в кружки с числом), «Где я», нажать на место → «Маршрут».

**ИИ-помощник**: сводка дня видна сразу. Чтобы он отвечал — вставь свой ключ на странице помощника («Свой ИИ»: Claude, OpenAI или Z.AI)
или впиши ключ площадки в `.env`. Проверить: «Отчёт за день», «Добавь привычку пить 8 стаканов воды», «Поставь встречу на завтра в 15:00».
Включить «Помощник может читать мои новые сообщения» → «Кто мне написал?» — должен пересказать.

**Сообщества**: Сервисы → «Сообщества» → «Создать» → добавить канал и категорию → со второго аккаунта вступить, написать в «общий»,
поставить себе ник → первый видит ник в канале. Убедиться, что каналы **не** появились в обычном списке чатов.

**Редактор фото**: в чате выбрать фото → «Кадр» (рамка, 1:1, поворот), «Цвет» (яркость, «Улучшить»), «Рисунок» (стрелка), «Текст» →
«Отправить» → фото пришло таким, каким было на экране. Профиль → сменить аватар → рамка-квадрат с кругом.

**Нижние кнопки**: Профиль → «Нижние кнопки» → поставить 7–8 своих, поменять порядок → панель листается → перезапустить:
приложение открывается на первой кнопке. На сайте: Настройки → «Нижние кнопки и стартовый экран» → «С чего начинать: Чаты».

**v51 — чаты**: отправить вертикальное фото (не квадрат), написать в группу (✓, после прочтения ✓✓), в поиске чатов набрать
название канала или слово из сообщения — всё в одном списке. Чаты → «Контакты» → добавить по номеру.

**v51 — сообщества**: Настройки сообщества → «Роли» → создать роль с цветом → выдать участнику → создать закрытый канал для этой роли →
второй аккаунт без роли канал не видит. «Голосовая» → войти с двух устройств (сайт) → слышно друг друга. «Доска задач».

**v51 — аккаунты**: Настройки → «Аккаунты» → «Добавить аккаунт» → войти вторым → переключиться обратно одним нажатием.

**v51 — статистика** (только тебе): `/moderation/stats/` — время по разделам, сколько людей вернулось.

**v52 — с ПК**: главная (слева меню, «Добрый день…», разделы по группам) → поиск в шапке: набрать имя человека или название сообщества →
«Чаты» (во весь экран) → сообщество → значок настроек у названия → разделы слева.

**v52 — маски**: Настройки → «Мои профили» → имя для объявлений, снять галочку «Показывать ссылку…» → открыть своё объявление вторым
аккаунтом: видно только это имя, «Написать продавцу» открывает чат, где продавец тоже под этим именем.

**v53 — безопасность**: страница входа → «Войти по QR-коду» → подтвердить с телефона. Настройки → «Устройства» → завершить чужой сеанс.
Настройки → «Двухшаговая защита» → подключить Google Authenticator → выйти и войти снова: просит код.

**v53 — витрина и чаты**: главная → плитки сервисов → «⋯» → «Выше / Ниже / Убрать». Чаты: список на месте (раньше был пуст без папок),
нажать на поиск — частые и недавние. Открытый канал: внизу объявление с пометкой «Реклама» (если создано в админке).

**v52 — закрытый профиль**: Настройки → Конфиденциальность → «Закрытый профиль» → второй аккаунт подписывается → «Заявка отправлена» →
первый: «Заявки в подписчики» → одобрить → записи стали видны.

## Чего НЕТ (честно)

### Можно сделать следующим шагом (ничего не мешает)
- **Опросы** в чатах и каналах (место под них в базе уже есть).
- **Выбор нескольких сообщений** сразу (переслать/удалить пачкой).
- **Переход из уведомления прямо к сообщению** (сейчас открывается чат).
- **Медиа чата** с листанием в профиле собеседника (сейчас — сетка без листания).
- **Превью ссылок** (картинка и заголовок сайта под ссылкой).
- **Таймер автоудаления** сообщений.
- **Темы в группах** (форумы как в Telegram), **заявки на вступление**, **подписи админов**.
- **Фон для отдельного чата** (сейчас один на все чаты).
- **Сообщества: события и календарь, свой аватар в сообществе, заявки на вступление.**
- **В приложении**: экран «Уведомления и звуки».
- **Имя контакта** в подписях сообщений в группах (в списке чатов и шапке — уже есть).
- **«Позвать поддержку» третьим** в чат с врачом или юристом.
- **Лента: видео в записях, отложенные записи, опросы в записях.**
- **Подарки и ilm4-shorts — экраны** (основа есть, включать вместе с оплатой и сервером).

### Только после покупки сервера
- Короткие видео и **видео в сторис** (хранение и раздача видео).
- Ссылки `ilm4.com/c/имя`, сразу открывающие приложение.
- **Голосовые комнаты больше 8 человек**, групповые звонки (медиасервер LiveKit), демонстрация экрана, записи встреч.
- Хранение файлов в объектном хранилище (S3), а не на диске сервера.
- Проверка под нагрузкой: Redis, несколько процессов, файлы 2 ГБ, PostgreSQL.

### Только в собранном приложении (EAS)
- Звонки, **голосовые комнаты сообществ (v52 — написаны, не запускались)**, пуши, сжатие видео на Android, жесты записи голоса/кружка — проверить.
- Рисование на видео, смена камеры в кружке без перезапуска записи.
- **Трансляция геопозиции** (live location).
- Секретные чаты (сквозное шифрование).
- Привязка сертификата (pinning) — перед выпуском в магазины.

### Отдельные большие этапы
- **Боты** как в Telegram (свой Bot API) — готовых ботов Telegram перенести нельзя.
- **Оплата** настоящими деньгами (кошелёк, платные подарки, платная подписка на ИИ).
- **ИИ-агент, который кодит на твоём ПК** — нужна программа-спутник на компьютере и строгая защита.
- Наборы узоров для фона от художника.

## Про ИИ-помощник — как устроено

- **Сводка дня** собирается без ИИ — бесплатно и мгновенно.
- **Свой ключ** — любой поставщик из списка (Claude, OpenAI, Z.AI, OpenRouter, DeepSeek), без лимита, платит сам человек.
  Ключ хранится зашифрованным.
- **Подписки Claude Pro / ChatGPT Plus подключить нельзя** — они не дают доступ чужим программам (правила этих компаний).
  Подписка **Z.AI Coding Plan** ключ выдаёт — она в списке; подходит ли она по их правилам для такого использования, уточни у них.
- **Ключ площадки** в `.env` — каждому N бесплатных сообщений в день (Настройки сайта). **Подписка ilm4** — «без лимита до…»
  выдаётся в админке; с оплатой из кошелька будет продлеваться сама.
- Читать тексты сообщений помощник может, только если человек сам это включил. Чаты никяха не передаются никогда.
- Новое умение — одна функция в `apps/assistant/tools.py`.
