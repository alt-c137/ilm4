Защита фото

Как мы бережём фотографии сестёр и братьев.

{% nk_icon 'eye_off' 'nkp__ic' %}
В ленте фото нет

Решение складывается по убеждениям и описанию, а не по внешности.

{% nk_icon 'heart' 'nkp__ic' %}
Только при взаимном интересе

Обмен фото начинается, когда интерес проявили оба. Сестра смотрит первой и решает, продолжать ли.

{% nk_icon 'clock' 'nkp__ic' %}
{{ minutes }} минут на решение

Фото показывается один раз. Время вышло без ответа — это отказ: никто не «зависает».

{% nk_icon 'id' 'nkp__ic' %}
Водяной знак с ID смотрящего

На каждом показе — ID и время. Утечка сразу указывает на источник: вечная блокировка.

{% nk_icon 'nophone' 'nkp__ic' %}
Скриншоты запрещены правилами

Честно: браузер и Telegram не умеют запрещать скриншоты. Поэтому — обещание перед показом, водяной знак и бан за нарушение.

{% nk_icon 'lock' 'nkp__ic' %}
Шифрование при хранении

Фото хранится на сервере зашифрованным. Модератор открывает его только для проверки анкеты — каждое открытие записывается в журнал.

{% nk_icon 'once' 'nkp__ic' %}
Одноразовый показ

Посмотрели и решили — повторно фото не открыть. Дальше, если захотите, делитесь фото уже в чате.

Правила раздела

  • Цель — никях. Флирт, «общение ради общения» и харам — блокировка.
  • Телефоны, ники, ссылки и соцсети в анкете запрещены — анкета не пройдёт проверку.
  • Всё в анкете — правда. За обман доступ закрывается.
  • Уважение к сёстрам и братьям. Жалобы рассматривает модератор.
