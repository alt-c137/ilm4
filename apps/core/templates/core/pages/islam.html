{% translate "Нужно ли менять имя?" %}

{% translate "Нет. Менять имя стоит, только если у него плохое значение. Многие мусульмане носят имена, данные при рождении." %}

{% translate "Нет. Шахаду можно произнести сразу, понимая смысл. Арабские слова намаза учатся постепенно — начните с «аль-Фатихи»." %}
