{% translate "Перед намазом" %}

  • {% translate "Чистота тела, одежды и места молитвы" %}
  • {% translate "Омовение (вуду), а после большого осквернения — гусль" %}
  • {% translate "Закрытый аурат: одежда, скрывающая тело, как положено шариатом" %}
  • {% translate "Наступило время намаза —" %} {% translate "расписание по вашему городу" %}
  • {% translate "Лицом к Кибле — в сторону Каабы в Мекке" %}
  • {% translate "Намерение (ният) в сердце: какой намаз вы совершаете" %}

{% translate "Омовение (вуду)" %}

  1. {% translate "Намерение и слова «Бисмиллях»" %}
  2. {% translate "Вымыть кисти рук — 3 раза" %}
  3. {% translate "Прополоскать рот — 3 раза" %}
  4. {% translate "Промыть нос — 3 раза" %}
  5. {% translate "Умыть лицо — от линии волос до подбородка и от уха до уха, 3 раза" %}
  6. {% translate "Вымыть руки до локтей, сначала правую, затем левую — 3 раза" %}
  7. {% translate "Провести влажными руками по голове (масх) и протереть уши" %}
  8. {% translate "Вымыть ноги до щиколоток, сначала правую, затем левую — 3 раза" %}

{% translate "Ракаат — один цикл молитвы: стояние, поклон и два земных поклона." %}

{% translate "Порядок намаза" %}

  1. {% translate "Такбир." %} {% translate "Встаньте лицом к Кибле, поднимите руки и скажите «Аллаху акбар» — намаз начался." %}
  2. {% translate "Стояние (кыям)." %} {% translate "Прочитайте суру «аль-Фатиха». В первых двух ракаатах после неё — ещё короткую суру или несколько аятов." %}
  3. {% translate "Поясной поклон (руку‘)." %} {% translate "Со словами «Аллаху акбар» наклонитесь, руки на коленях: «Субхана Раббияль-‘Азым» — 3 раза." %}
  4. {% translate "Выпрямление." %} {% translate "«Сами‘а-Ллаху лиман хамидах», затем «Раббана ва лякаль-хамд»." %}
  5. {% translate "Земной поклон (суджуд)." %} {% translate "Со словами «Аллаху акбар» опуститесь лбом и носом на землю: «Субхана Раббияль-А‘ля» — 3 раза." %}
  6. {% translate "Короткое сидение" %}{% translate ", затем второй земной поклон — так завершается ракаат." %}
  7. {% translate "Ташаххуд." %} {% translate "После каждых двух ракаатов сядьте и прочитайте «ат-Тахият». В последнем ракаате добавьте салават Пророку" %} ﷺ.
  8. {% translate "Салям." %} {% translate "Поверните голову направо, затем налево: «Ас-саляму ‘алейкум ва рахматуллах» — намаз завершён." %}
