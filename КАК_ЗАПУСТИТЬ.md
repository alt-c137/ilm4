# Как запустить ilm4 и что подключить

Коротко: **сначала всё тестируешь на своём ПК** (бесплатно, с настоящим Telegram-ботом и https),
потом арендуешь сервер и переносишь ту же сборку.

- **Все ключи, API и где прописать домен** — в **`ПОДКЛЮЧЕНИЯ.md`** (карта, капча, ИИ, оплаты, почта, бот…).
- **Мобильное приложение** (Android/iOS) — `mobile/README.md`: посмотреть на своём телефоне — `bash scripts/app_setup.sh`, затем `bash scripts/run_app.sh`.
- Сервер, база, безопасность — `docs/LAUNCH.md`.
- Языки интерфейса: русский, узбекский, английский (кнопка «RU» в шапке сайта, в приложении — Профиль → Настройки).
  Новые тексты переводятся в `locale/uz.json` и `locale/en.json`, затем `.venv/bin/python scripts/i18n_build.py`.

---

## 1. Тест на своём ПК (бесплатно, без ngrok и регистраций)

> **Почему не ngrok.** Бесплатный ngrok показывает браузерам свою страницу-предупреждение «You are about to visit…»
> и подменяет ею даже файлы оформления — поэтому у людей, которые открывают ссылку с телефона (особенно из
> Telegram), сайт выглядит «голым»: крупные синие кнопки, чёрные значки, без дизайна. Скрипт `run_local.sh`
> даёт адрес Cloudflare (или localhost.run) — там такой страницы нет.

Всё делается в терминале **Ubuntu (WSL)**.

### 1.1. Один раз: установить

```bash
cd ~/projects/ilm4
python3 -m venv .venv
.venv/bin/pip install -r requirements/dev.txt
cp .env.example .env        # если .env ещё нет
```

### 1.2. Один раз: создать бота в Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин (например `ilm4_nikah_bot`).
   BotFather пришлёт **токен** вида `123456:ABC...`.
2. Откройте `.env` (`nano .env`) и впишите:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_BOT_USERNAME=ilm4_nikah_bot
   ```
3. **Группа модераторов** (сюда бот присылает анкеты и видео-кружки с кнопками «Одобрить/Отклонить»):
   - создайте группу в Telegram, добавьте в неё бота и модераторов;
   - запустите сайт (шаг 1.3), напишите в группе `/id` — бот ответит числом `-100…`;
   - впишите в `.env`: `TELEGRAM_MODERATION_CHAT_ID=-100…`;
   - (по желанию) кто может нажимать кнопки: напишите боту в личку `/id`, получите свой id и впишите
     `TELEGRAM_MODERATOR_IDS=12345,67890`. Если пусто — одобрять может любой участник группы.

### 1.3. Каждый раз: запуск

```bash
bash scripts/run_local.sh
```

Скрипт сам:
- применит миграции;
- запустит сайт;
- откроет бесплатный **https-туннель Cloudflare** (адрес вида `https://какие-то-слова.trycloudflare.com`, меняется при каждом запуске);
- направит на этот адрес кнопку «Никях» в боте;
- запустит бота.

В терминале появится адрес сайта. **В Telegram:** откройте своего бота → `/start` → кнопка **«Никях»**. Откроется никях: вход автоматический, по Telegram.

Остановить — `Ctrl+C`. Пока скрипт работает и ПК включён, сайтом можно пользоваться с телефона и давать ссылку другим для теста.

> Если сразу после запуска адрес не открывается — подождите минуту: новому адресу нужно время, чтобы «разойтись» по интернету.

### 1.4. Админка

`https://…trycloudflare.com/admin/` или `http://127.0.0.1:8000/admin/`.
Логин **isa**; новый пароль — `.venv/bin/python manage.py changepassword isa`.
Сбросить 2FA — команда в `docs/LAUNCH.md`, раздел 1.

## 2. Что работает сразу, а что нужно подключить

| Что | Без ключей | Что сделать |
|---|---|---|
| Сайт, лента-свайп, анкеты, чат, звонки | ✅ | — |
| Telegram: мини-приложение, уведомления, модерация, верификация кружком | нужен бот | раздел 1.2 |
| **Оплата Telegram Stars** | ✅ если есть бот | только курс звезды в админке (раздел 3.1) |
| Оплата картами Uzcard / Humo (Click) | ❌ | раздел 3.2 |
| Оплата картами мира, Apple/Google Pay (Stripe) | ❌ | раздел 3.3 |
| Оплата криптой (NOWPayments) | ❌ | раздел 3.4 |
| Карта (хорошая подложка) | ✅ запасная OSM/Esri | ключ MapTiler — раздел 4 |
| Письма «забыли пароль» | ❌ (в консоль) | SMTP — раздел 5 |
| Вход через Google | ❌ | раздел 6 |
| Звонки через мобильный интернет | частично | TURN — раздел 7 |

## 3. Оплата

Все способы пополняют **баланс** в сумах. С баланса покупаются премиум, возврат анкет,
поднятие анкеты, открытие чата (если цена задана). Цены — в админке → «Настройки сайта».
Способ сам появляется на странице пополнения, как только вписаны его ключи.

**Важно про Telegram:** цифровые услуги внутри Telegram-бота (премиум и т. п.) по правилам
Telegram продаются за **Stars**. Карты и крипта работают на сайте.

### 3.1. Telegram Stars — ничего подключать не нужно
- Работает, как только настроен бот. Внутри Telegram оплата — окно Telegram, 2 касания.
- Админка → «Настройки сайта» → **«Telegram Stars: сум за 1 звезду»** (по умолчанию 250).
- Звёзды копятся на балансе бота; вывести их можно через @BotFather → Bot → Monetization (Fragment → TON).

### 3.2. Click — карты Uzcard и Humo
1. Нужен **ИП или ООО** в Узбекистане. Заявка — на сайте click.uz → «Бизнесу» → подключение мерчанта.
2. В кабинете merchant.click.uz создайте сервис; впишите адреса:
   - **Prepare URL:** `https://ВАШ-ДОМЕН/payments/click/prepare/`
   - **Complete URL:** `https://ВАШ-ДОМЕН/payments/click/complete/`
3. Скопируйте в `.env`: `CLICK_SERVICE_ID`, `CLICK_MERCHANT_ID`, `CLICK_SECRET_KEY`.
4. Проверьте платёж на маленькой сумме.

### 3.3. Stripe — Visa/Mastercard всего мира, Apple Pay, Google Pay
1. Stripe **не открывает счета компаниям из Узбекистана** — нужна компания в поддерживаемой стране
   (ОАЭ, Великобритания, США через Stripe Atlas и т. п.).
2. dashboard.stripe.com → Developers → API keys → `STRIPE_SECRET_KEY=sk_live_…`.
3. Developers → Webhooks → Add endpoint: `https://ВАШ-ДОМЕН/payments/stripe/webhook/`,
   событие `checkout.session.completed` → **Signing secret** → `STRIPE_WEBHOOK_SECRET=whsec_…`.
4. Сумма в сумах пересчитывается в доллары по текущему курсу.

### 3.4. Криптовалюта — NOWPayments (USDT, BTC, ETH…)
1. Регистрация на nowpayments.io (компания не обязательна), укажите кошелёк для выплат.
2. Settings → API keys → `NOWPAYMENTS_API_KEY`; Settings → Payments → IPN secret → `NOWPAYMENTS_IPN_SECRET`.
3. Адрес уведомлений передаётся сам (`/payments/crypto/ipn/`).

### Не подключено и почему
- **СБП, карты России (ЮKassa, CloudPayments)** — нужно юрлицо в РФ. Если появится — добавлю за день.
- **PayPal** — не работает для получателей из Узбекистана.
- **Payme** — можно вместо или вместе с Click (нужен тот же ИП/ООО), добавлю по запросу.

> Все оплаты проверены тестами на поддельных подписях и повторах (деньги не зачисляются дважды,
> чужой счёт оплатить нельзя). **Первую настоящую оплату каждым способом сделайте на маленькую сумму.**

## 4. Карта
cloud.maptiler.com → регистрация → **API keys** → скопировать ключ → в ключе разрешить только свой домен →
админка → «Настройки сайта» → **«карта: ключ MapTiler»**. Без ключа карта работает на запасных подложках.

## 5. Почта («забыли пароль»)
Brevo (brevo.com, 300 писем в день бесплатно) → SMTP & API → SMTP ключ → в `.env`:
```
EMAIL_URL=smtp+tls://ЛОГИН:КЛЮЧ@smtp-relay.brevo.com:587
DEFAULT_FROM_EMAIL=ilm4 <noreply@ВАШ-ДОМЕН>
```

## 6. Вход через Google
console.cloud.google.com → APIs & Services → Credentials → Create OAuth client ID (Web) →
Redirect URI: `https://ВАШ-ДОМЕН/accounts/google/callback/` → в `.env`:
`GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`.

## 7. Звонки через мобильный интернет (TURN)
metered.ca (есть бесплатный лимит) или свой coturn на сервере → админка → «Настройки сайта» → поля «звонки: TURN».

## 8. Когда всё проверил — сервер

1. Арендовать VPS: Ubuntu, 2 ядра / 4 ГБ (≈ 5–8 $/мес — Hetzner, Timeweb, Aeza).
2. Купить домен, подключить Cloudflare (https бесплатно).
3. На сервере:
   ```bash
   curl -fsSL https://get.docker.com | sh
   git clone <ссылка-на-репозиторий> ilm4 && cd ilm4
   cp .env.example .env && nano .env
   ```
   В `.env` — всё из разделов выше плюс:
   ```
   SECRET_KEY=…            # python3 -c "import secrets;print(secrets.token_urlsafe(50))"
   POSTGRES_PASSWORD=…
   ALLOWED_HOSTS=ваш-домен.com
   CSRF_TRUSTED_ORIGINS=https://ваш-домен.com
   SITE_URL=https://ваш-домен.com
   CHAT_ENCRYPTION_KEY=…   # сохранить копию! (команда — в docs/LAUNCH.md)
   TELEGRAM_WEBHOOK_SECRET=любая-длинная-строка
   SECURE_SSL=True
   ```
4. `docker compose -f docker-compose.prod.yml up -d --build` — сайт, база, бот (вебхук включится сам), фоновые задачи.
5. Бэкапы: `sh scripts/backup.sh` + ночной cron (`docs/LAUNCH.md`, раздел 2).

**Данные с ПК на сервер не переносятся автоматически** (на ПК — тестовая база SQLite). На сервере создайте админа заново:
`docker compose -f docker-compose.prod.yml exec app python manage.py createsuperuser`.

## 9. Только никях, отдельно
Если никях нужен отдельным сайтом или ботом: в `.env` нового сервера `SITE_MODE=nikah` — главная откроет
никях, остальные разделы закроются. Перенос анкет: `nikah_export` / `nikah_import` (`docs/LAUNCH.md`, раздел 7).
