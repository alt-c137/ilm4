# ilm4 — запуск: ПК, сервер, подключения

Коротко: сайт готов к запуску на одном VPS через Docker. Без внешних ключей
работает всё, кроме входа через Google, писем, пополнения баланса и надёжных
звонков через мобильный интернет. Ниже — что и где подключить.

---

## 1. Запуск на своём ПК (Windows + WSL)

```bash
cd ~/projects/ilm4
source .venv/bin/activate
pip install -r requirements/dev.txt      # один раз / после обновлений
python manage.py migrate                 # применить новые миграции
python manage.py runserver               # http://127.0.0.1:8000
```

База на ПК — файл `db.sqlite3` (SQLite), ничего ставить не нужно.
Камера и микрофон (голосовые, кружки, звонки) работают только на
`localhost` или по https (ngrok).

### Вход в админку (`/admin/`)

Суперпользователь уже есть: логин **isa** (вход по его email).
Пароль забыт — задать новый:

```bash
python manage.py changepassword isa
```

После пароля админка попросит **код 2FA** из приложения-аутентификатора
(Google Authenticator и т. п.), куда был добавлен «ilm4». Если телефона с этим
кодом нет — сбросить 2FA (при следующем входе покажет новый QR):

```bash
python manage.py shell -c "from django_otp.plugins.otp_totp.models import TOTPDevice; TOTPDevice.objects.filter(user__username='isa').delete()"
```

Новый админ: `python manage.py createsuperuser`.

### Полная «серверная» сборка на своём ПК

Да, на ПК можно поднять **то же самое, что на сервере**: PostgreSQL, Redis, daphne, nginx
и фоновые задачи. Это удобно, чтобы проверить всё перед выкладкой.

1. Установить **Docker Desktop** (Windows) → Settings → Resources → WSL Integration → включить Ubuntu.
2. В папке проекта: `cp .env.example .env` и вписать `SECRET_KEY`, `POSTGRES_PASSWORD`,
   `ALLOWED_HOSTS=localhost,127.0.0.1`.
3. `docker compose -f docker-compose.prod.yml up -d --build` — сайт на http://localhost.
4. `docker compose -f docker-compose.prod.yml exec app python manage.py createsuperuser`.

**Но ПК — не замена серверу.** Сайт работает, пока включён компьютер, а домашний интернет
обычно не даёт постоянного адреса. Показать сайт людям с ПК временно можно через
**Cloudflare Tunnel** (`cloudflared tunnel --url http://localhost`) — без открытия портов.
Для запуска — VPS (раздел 2).

## 2. Запуск на сервере

**Сервер:** любой VPS с Ubuntu 22/24, 2 vCPU / 4 ГБ RAM / 40+ ГБ диска
(Hetzner CX22 ≈ 4–5 €/мес, Timeweb/Aeza ≈ 5–8 $/мес). Подробнее о росте и
цене — `docs/ROADMAP.md`.

```bash
# 1) Docker на сервере
curl -fsSL https://get.docker.com | sh

# 2) Код и настройки
git clone <ссылка-на-репозиторий> ilm4 && cd ilm4
cp .env.example .env && nano .env
```

В `.env` обязательно:

| Переменная | Что вписать |
|---|---|
| `SECRET_KEY` | `python3 -c "import secrets;print(secrets.token_urlsafe(50))"` |
| `POSTGRES_PASSWORD` | длинный случайный пароль |
| `ALLOWED_HOSTS` | `ilm4.com,www.ilm4.com,<IP сервера>` |
| `CSRF_TRUSTED_ORIGINS` | `https://ilm4.com,https://www.ilm4.com` |
| `CHAT_ENCRYPTION_KEY` | `python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` — **сохранить копию**, без ключа переписку не прочитать |
| `SECURE_SSL` | `True` — после подключения Cloudflare (шаг 3) |

```bash
# 3) Старт (БД, Redis, сайт, nginx, фоновые задачи)
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec app python manage.py createsuperuser

# Обновление после git push
git pull && docker compose -f docker-compose.prod.yml up -d --build

# Логи, если что-то не так
docker compose -f docker-compose.prod.yml logs -f app
```

Что поднимается: `db` (PostgreSQL 16 + PostGIS), `redis` (чат/звонки, кэш,
лимиты), `app` (daphne: страницы + WebSocket), `nginx` (порт 80, статика,
медиа), `jobs` (раз в час автопринятие сделок, раз в 6 ч курсы валют).
Миграции и сборка статики выполняются автоматически при старте.

**Бэкапы** — обязательно с первого дня:

```bash
sh scripts/backup.sh          # вручную
crontab -e                    # каждую ночь:
# 30 3 * * * cd /root/ilm4 && sh scripts/backup.sh >> backups/backup.log 2>&1
```

Раз в неделю скачивайте свежую копию с сервера (или в облако).

## 3. Что подключить

| Что | Зачем | Где взять | Куда вписать | Статус кода |
|---|---|---|---|---|
| **Домен + Cloudflare** | https, защита от атак, CDN | регистратор домена → DNS на Cloudflare, A-запись на IP сервера, SSL «Flexible» (позже «Full») | `.env`: `SECURE_SSL=True`, `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS` | ✅ готов |
| **Вход через Google** | регистрация в 1 клик | Google Cloud Console → APIs & Services → Credentials → OAuth client ID (Web). Redirect URI: `https://ilm4.com/accounts/google/callback/` | `.env`: `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET` | ✅ готов |
| **Почта (SMTP)** | «Забыли пароль?» | Brevo (300 писем/день бесплатно), Mailgun, Яндекс 360 | `.env`: `EMAIL_URL=smtp+tls://логин:пароль@smtp-relay.brevo.com:587`, `DEFAULT_FROM_EMAIL` | ✅ готов |
| **TURN-сервер** | звонки через мобильный интернет | coturn на этом же VPS или Metered.ca (есть бесплатный лимит) | админка → Настройки сайта → `webrtc_turn_*` | ✅ готов |
| **Карта** | карта халяль/мечетей | cloud.maptiler.com → API keys (в ключе разрешить только свой домен) | админка → Настройки сайта → «карта: ключ MapTiler» | ✅ готов. Без ключа — запасные OpenStreetMap → Esri (автопереключение, если подложка не грузится). Для коммерческого трафика нужен платный тариф MapTiler или другой провайдер |
| **Telegram (никях)** | открыть никях внутри Telegram, уведомления о симпатии | @BotFather → /newbot → токен; затем /setmenubutton (или /newapp) → URL `https://ilm4.com/nikah/` | `.env`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `SITE_URL=https://ilm4.com` | ✅ готов (вход по подписи Telegram; в web.telegram.org в браузере не работает — только приложения Telegram) |
| **Пополнение: карты UZ** | баланс кошелька | Payme Business / Click — нужен ИП/ООО и договор мерчанта | `.env`: `PAYME_MERCHANT_ID`, `PAYME_SECRET` | ⚠️ только заготовка: обмен с Payme и вебхук надо дописать (~2–3 дня) |
| **Пополнение: Visa/MC** | международные карты | Stripe — только на компанию в поддерживаемой стране (не UZ) | `.env`: `STRIPE_*` | ⚠️ заготовка |
| **Пополнение: крипта** | USDT/BTC | NOWPayments, CryptoCloud | `.env`: `CRYPTO_GATEWAY_*` | ⚠️ заготовка |
| **SMS** | подтверждение телефона | Eskiz.uz / Play Mobile (UZ), Twilio (мир) | — | ❌ нет в коде: сейчас телефон не подтверждается |
| **Мониторинг** | узнать, что сайт упал | UptimeRobot (бесплатно), Sentry (ошибки) | — | по желанию |

Пока ключей нет, соответствующая кнопка просто не показывается или пишет
«скоро» — сайт не падает.

**Деньги.** Хранение чужих денег (эскроу, вывод) юридически требует
лицензии/партнёра-банка. Поэтому `escrow_enabled` и `wallet_payouts_enabled`
по умолчанию выключены: баланс тратится только на услуги платформы.

## 4. База данных

- **Сервер:** PostgreSQL 16 + PostGIS 3.4 (образ `postgis/postgis`), всё
  настроено в `docker-compose.prod.yml`. Подключение — `DATABASE_URL` в compose,
  руками ничего настраивать не нужно. В образ приложения добавлены GDAL/GEOS
  (без них Django не подключится к PostGIS).
- **PostGIS сейчас установлен, но не используется**: «мечеть рядом» считает
  расстояние в Python — для тысяч мест этого хватает. Когда мест станет
  десятки тысяч, переведём координаты в `PointField` с гео-индексом.
- **На ПК:** SQLite. Миграции проверены на SQLite; на PostgreSQL их первым
  прогонит сервер. Чтобы проверить заранее: Docker Desktop → Settings →
  Resources → WSL Integration → Ubuntu, затем `docker compose up -d` и в `.env`
  раскомментировать `DATABASE_URL`.
- **Redis** — в compose; держит чат, звонки, кэш и лимиты попыток.

## 6. Никях v2 (24.09.2026)

- **Мастер анкеты на 15 шагов:** имя, возраст и желаемый возраст, страна и национальность, рост и вес, семейное положение (брат — какую по счёту жену ищет, сестра — готова ли быть не единственной), мазхаб, вероубеждение, намаз, Коран, «где Аллах», дети, сроки, борода или покрытие, манхадж своими словами, переезд, о себе, кого ищу, фото, закрытые вопросы о религии, обязательства. Черновик сохраняется в браузере.
- **Лента без фото.** Показывается совместимость в процентах и что именно совпало. Есть фильтры по возрасту, стране, городу, акыде, мазхабу и семейному положению.
- **Симпатия.** «❤ Интерес» → взаимный интерес → обмен фото → чат. Фото хранится **зашифрованным**. Сестра смотрит первой. Показ одноразовый, длится N минут (настраивается), на снимке водяной знак с ID смотрящего. Молчание засчитывается как отказ. Если кто-то выбрал «без фото», чат открывается сразу.
- **Модерация:** любая анкета и любая правка уходят на проверку. Телефоны, ники и ссылки в текстах отсекаются автоматически. Закрытые ответы видит только модератор (фильтр «тревожные ответы»). Модератор может открыть фото из админки, это пишется в журнал.
- **Цена чата для брата** — админка → «никях: цена открытия чата» (по умолчанию 0, пока не подключено пополнение).
- **Лента-колода (v3):** свайп влево — пропустить, вправо — интерес. Карточка наклоняется, по центру растёт красный ✕ или зелёный ✓ со свечением. Есть кнопки и стрелки клавиатуры. Без премиума действует лимит анкет в день (админка → «никях: анкет в день», по умолчанию 20). Пропущенных можно вернуть: платно или бесплатно с премиумом.
- **Фильтры:** страна, город, группы национальностей, возраст, рост и вес двойными ползунками, мазхаб, акыда, намаз, сроки, статус, покрытие или борода, дети, переезд. Переключатели: с фото, в сети (премиум), без детей, не был(а) в браке, многожёнство. Фильтры хранятся в сессии.
- **Премиум** (админка → никях: премиум, цена, дней): без дневного лимита, бесплатный возврат отклонённых, «в сети». Покупается с баланса. Фото и совместимость премиум не открывает. Баланс и премиум показаны в шапке раздела.
- **Фото через Telegram:** если человек вошёл из Telegram, фото можно открыть сообщением бота с `protect_content`. Telegram запрещает пересылку и сохранение, на Android обычно блокирует и скриншот. Бот удаляет фото по таймеру: сервис `jobs` раз в минуту запускает `nikah_cleanup`. В браузере фото рисуется на canvas и прячется при потере фокуса, сворачивании, PrintScreen и печати. Это сдерживание, а не гарантия.
- **Честно о скриншотах:** браузер и Telegram не умеют запрещать скриншоты. Защищают обещание перед показом, водяной знак, одноразовость и бан. Настоящий запрет возможен только в нативном приложении (Android `FLAG_SECURE`).

**Не сделано (следующие шаги):** оплата премиума картой (сейчас только с баланса, а пополнение ещё не подключено), нативное приложение с запретом скриншотов, селфи-верификация, махрам или свидетель в чате никяха, жалобы на анкету, переводы на другие языки, ИИ-модерация переписки.

## 7. Отделить никях в отдельную установку

Никях — самостоятельный раздел. Если его нужно запустить отдельно (своим доменом, своим
сервером, своей базой), это делается **без переписывания кода**: тот же репозиторий, одна
переменная.

1. Новый сервер — как в разделе 2, но в `.env`: `SITE_MODE=nikah` и **тот же**
   `CHAT_ENCRYPTION_KEY`, что на основном (им зашифрованы фото анкет и архив переноса).
   Главная сразу ведёт в никях, остальные разделы платформы закрыты (404), меню скрыто.
   Работают только никях, чат и кошелёк.
2. Перенести данные:
   ```bash
   # на основном сервере
   docker compose -f docker-compose.prod.yml exec app python manage.py nikah_export /app/media/nikah.zip
   # скопировать nikah.zip на новый сервер (scp), затем там:
   docker compose -f docker-compose.prod.yml exec app python manage.py nikah_import /app/media/nikah.zip
   ```
   Переносятся анкеты, фото (зашифрованными), интересы, пропуски, закладки, пары и их
   переписка, а также аккаунты с тем же паролем и Telegram. Архив целиком зашифрован.
   Балансы кошелька не переносятся — их сверяют вручную.
3. На основном сайте раздел «Никах» выключить: админка → Разделы → Никах → «выкл.»
   (или «скоро»). Telegram-бот переключить на новый адрес (`/setmenubutton`).

**Известно, не критично к запуску:**

- Нет подтверждения email при регистрации и капчи. Боты могут
  регистрироваться, а чужой email можно «занять» заранее. Рекомендуем
  Cloudflare Turnstile и письмо-подтверждение.
- Отзывы может оставить любой вошедший пользователь, без сделки. Накрутку
  разбирает модерация.
- TURN-логин виден участникам чата; при росте перейти на временные логины.
- Переписка шифруется в базе (Fernet), это **не** сквозное шифрование
  (E2E). Администратор сервера с ключом может её прочитать.
