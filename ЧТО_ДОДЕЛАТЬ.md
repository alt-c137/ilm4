### 🖥 На сервере (появится, когда купим сервер)

| Что | Что именно проверить |
|---|---|
| Несколько рабочих процессов (uvicorn) | На ПК проверено: чат, звонки-сигналы, загрузка 20 МБ, перезапуск упавшего процесса. На сервере — то же с Redis: сообщение доходит, когда собеседники попали в разные процессы |
| Набор соединений с базой | Включается `DB_POOL=True` в `.env`. На ПК нет PostgreSQL — не проверял. Включить, убедиться, что сайт стартует |
| nginx: сжатие, ограничение частоты, кеш статики | `curl -I` — у страниц `content-encoding: gzip`, у статики `cache-control: immutable` |
| Файл 2 ГБ целиком | На ПК проверено 20 МБ (5 частей). Большой — на сервере, заодно замерить скорость скачивания |
| Страна по Cloudflare | Заголовок `CF-IPCountry` → валюта по умолчанию |

## 3. Не сделано — большие этапы

| Этап | Что это | Почему не сейчас |
|---|---|---|
| ⏳ Боты (как в Telegram) | Чтобы чужие боты можно было подключать к ilm4 | Нужен свой «Bot API» (токены, вебхуки, команды, кнопки) — отдельный большой этап; готовых ботов Telegram перенести нельзя, их авторам придётся подключать их к нам |
| ⏳ Сторис и короткие видео (ilm4-shorts) | Лента коротких видео, истории на 24 часа | Тяжёлая часть — хранение и раздача видео; делать после покупки сервера |
| ⏳ Рисование на видео | Сейчас рисовать можно только на фото | Нужна перекодировка видео на телефоне — только в собранном приложении, отдельным модулем |
| ⏳ Свои папки чатов, архив, закреплённые чаты | Как вкладки «Личные / Боты / …» в Telegram, которые человек делает сам | Сейчас папки собираются сами по типу чата |
| ⏳ Наборы узоров для фона, как в Telegram | Сейчас 5 нейтральных узоров + цвет + фото | Рисованные наборы — работа художника |
| ⏳ Смена камеры в кружке без перезапуска записи | Сейчас при смене камеры кружок начинается заново | Ограничение камеры в Expo; решается своим модулем камеры при сборке приложения |
| ⏳ Индикатор «печатает…» | Как в Telegram под именем | Вместе с ответами и реакциями |
| ⏳ Ответы, реакции, закреп, упоминания, опросы | «Мелочи» мессенджера, к которым привыкли в Telegram | Следующий шаг после групп и каналов |
| ⏳ Комментарии к постам канала | Обсуждение под постом | Вместе с ответами и реакциями |
| ⏳ Ссылки `ilm4.com/c/имя` открывают приложение | Сейчас ссылка открывает сайт; в приложении канал находится через поиск | Нужна настройка домена (универсальные ссылки) — после покупки сервера |
| ⏳ Секретные чаты | Сквозное шифрование по протоколу Signal, только в приложении | Нужна готовая проверенная библиотека и сборка приложения |
| ⏳ Привязка сертификата (pinning) | Защита от подмены сервера | Делается перед выпуском в магазины, когда есть боевой сертификат |
| ⏳ Хранилище ключей (KMS) | Главный ключ шифрования не в `.env`, а в отдельном сервисе | Нужен сервер и инфраструктура |
| ⏳ Групповые звонки | Отдельный медиасервер (LiveKit) | После групп |
| ⏳ Сжатие видео на iPhone под настройку «1080p» | Сейчас iPhone всегда жмёт до 720p при выборе | Мелочь; сервер всё равно приводит к настройке |
| ⏳ Отдача больших файлов мимо Python | Сейчас сервер расшифровывает файл на лету при скачивании; для тысяч скачиваний одновременно нужен отдельный сервис | Понадобится при большой нагрузке |
| ⏳ Никях: фото на ключах v2 | Фото анкет пока на старом ключе (`CHAT_ENCRYPTION_KEY`) | Работает, перевод — аккуратная отдельная задача |

Подробности по мессенджеру — [docs/MESSENGER.md](docs/MESSENGER.md), раздел «План и статус».
