# Мобильное приложение ilm4 (Android и iOS)

Это **полноценное приложение** на React Native (Expo), не обёртка сайта: свои экраны, свои жесты,
работает без интернета там, где это возможно. Данные берёт с того же сервера ilm4 через API
(`/api/v1/…`), поэтому аккаунт, анкеты, чаты и публикации — общие с сайтом и Telegram-ботом.

## Что умеет

| Раздел | Что есть |
|---|---|
| **Намаз** | время считается **на телефоне, без интернета** (тот же расчёт, что на сайте, до минуты); город из списка или **GPS**; 5 методов, Аср по ханафитскому мазхабу; **азан-напоминания** (вовремя или за 5–30 минут); расписание на 30 дней; **Кибла** с живым компасом; погода |
| **Главная** | дата по хиджре, отсчёт до намаза, хадис дня, новости, курсы валют, быстрые разделы |
| **Сервисы** | все разделы из админки: выключили раздел — он исчезает и в приложении, без обновления |
| **Объявления, работа, услуги, перевозки, врачи, книги, форум, истории** | списки с поиском и категориями, карточка, «Написать автору», звонок, «Поделиться», жалоба; ответы на форуме; **подача прямо в приложении** (с договором автора, фото, датой, GPS для мест) |
| **Мои публикации** | статус проверки, изменить, скрыть, удалить — все разделы в одном месте |
| **Халяль-места** | **карта** с метками и точкой «я здесь» (MapTiler из админки или OpenStreetMap), список по расстоянию, открыть в картах телефона, добавить место |
| **Никях** | лента-**свайп** (наклон карточки, крестик/галочка), фильтры с двойными ползунками, анкета из 15 шагов, симпатии и пары, **обмен фото** (сестра первая, обещание, таймер, водяной знак), премиум, возврат отклонённых, пауза анкеты |
| **Чаты** | живые сообщения, фото и видео (из галереи или камерой), **голосовые**, **видеокружки** (запись и просмотр), **аудио- и видеозвонки** (с сайтом тоже), входящий звонок на любом экране, «прочитано ✓✓»; всё, что выключено в админке, пропадает и здесь |
| **Профиль** | баланс, уведомления, язык (ru / uz / en), тема (светлая / тёмная / как в телефоне), удаление аккаунта |
| **Вход** | email и пароль или **через Telegram-бота** (без пароля) |
| **Без интернета** | всё, что открывали, показывается из памяти телефона; наверху плашка «Нет интернета» |

**Защита никяха:** на всех экранах никяха и в чате пары **скриншоты и запись экрана запрещены**
(Android — полностью; iPhone — iOS 13+ скрывает содержимое на скриншоте и записи). Фото пары не
сохраняется в кеш, скрывается при сворачивании приложения.

Пополнение баланса и добавление книги (файл) открываются на сайте **уже со входом** (одноразовая ссылка):
оплата картой по правилам магазинов должна идти через платёжную страницу.

## Expo Go — это приложение или сайт?
**Приложение.** Expo Go — «проигрыватель» для разработки: он запускает **наш код приложения** (те же
экраны, что будут в магазине), а не сайт. Отличия от собранного приложения ilm4 (APK / App Store):
- открывается внутри Expo Go, а не своей иконкой ilm4;
- **нет звонков** (модуля WebRTC нет в Expo Go) и **нет пушей с сервера** на Android.

Всё остальное — одинаково. Для своей иконки, звонков и пушей — сборка из раздела 2 (APK ставится на телефон как обычное приложение).

## 1. Посмотреть на своём телефоне (бесплатно, 10 минут)

Нужно: ПК с Ubuntu (WSL), телефон с приложением **Expo Go** (Play Market / App Store).

```bash
cd ~/projects/ilm4
bash scripts/app_setup.sh        # один раз: Node.js и модули приложения
```

Потом каждый раз — два окна Ubuntu:

```bash
bash scripts/run_local.sh        # окно 1: сайт + https-адрес (адрес сам пропишется для приложения)
```
```bash
bash scripts/run_app.sh          # окно 2: появится QR-код
```

На телефоне: Expo Go → «Scan QR code» → наведите на QR-код. Приложение откроется.
Любая правка кода — телефон обновляется сам.

> В Expo Go **не работают пуш-уведомления с сервера** (ограничение Expo Go на Android).
> Азан-напоминания, скриншот-защита и всё остальное — работают. Пуши — в собранном приложении (раздел 2).

Без `run_local.sh` приложение ходит на боевой сервер `https://ilm4.com`.

## 2. Собрать настоящее приложение (APK / для магазинов)

Сборка идёт **в облаке Expo (EAS)** — Android Studio и Mac не нужны. Бесплатно ~30 сборок в месяц.

1. Регистрация: **expo.dev** → Sign up (бесплатно).
2. В папке приложения:
   ```bash
   cd ~/projects/ilm4/mobile
   npx eas-cli@latest login
   npx eas-cli@latest init          # создаст проект и впишет projectId в app.json (нужен для пушей)
   ```
3. **APK для своего телефона / тестеров:**
   ```bash
   npm run build:apk
   ```
   Через 10–20 минут придёт ссылка — открыть на Android и установить.
4. **Для Google Play** (файл AAB): `npm run build:android`, затем `npm run submit:android`.
5. **Для App Store:** `npm run build:ios` (Expo спросит логин Apple Developer), затем `npm run submit:ios`.

Ключи подписи Expo хранит сам — **не удаляйте проект на expo.dev**, иначе обновление в магазине не выпустить.

### Пуш-уведомления (сообщения, симпатии, «ваша очередь»)
Сервер отправляет их сам (через бесплатный Expo Push) — настраивать на сервере ничего не нужно. Нужно:
- **Android:** Firebase → проект → добавить Android-приложение `com.ilm4.app` → скачать
  `google-services.json` → `npx eas-cli@latest credentials` → Android → «Google Service Account / FCM V1» —
  загрузить ключ сервисного аккаунта (подробно: docs.expo.dev/push-notifications/fcm-credentials).
- **iOS:** при первой сборке `build:ios` Expo сам предложит создать ключ пушей — ответить «Yes».

## 3. Обновления

- **Сервер** (разделы, выключатели, тексты, цены) — приложение подхватывает **сразу**, без обновления.
- **Код приложения** — новая сборка (`build:android` / `build:ios`) и отправка в магазин.
- Заставить обновиться: админка → «Настройки сайта» → **«приложение: минимальная версия»** (например `1.1.0`) —
  у старых версий появится экран «Обновите приложение».
- Объявление всем пользователям приложения: поле **«приложение: объявление вверху»**.

## 5. Git
Приложение — папка `mobile/` **в том же репозитории**, что и сервер (так проще: API и приложение меняются
вместе, одна команда `git push`). Отдельный репозиторий не нужен. `node_modules`, `.expo`, `mobile/.env.local`
и ключи подписи в git не попадают (`mobile/.gitignore`). После `npx eas-cli init` изменится `mobile/app.json`
(появится `projectId`) — его нужно закоммитить.

## 6. Для разработчика

- Код: `src/app/` — экраны (Expo Router), `src/lib/` — API, намаз, уведомления, языки; `src/ui/` — элементы.
- Переводы: `src/lib/locales/uz.ts`, `en.ts` (ключ — русский текст). Что не переведено:
  `python3 scripts/app_i18n.py` (из корня проекта).
- Проверка: `npm run typecheck`, `npm run lint`, `npx expo-doctor`.
- Адрес сервера: `mobile/.env.local` → `EXPO_PUBLIC_API_URL=…` (по умолчанию `https://ilm4.com`).
- API сервера: `apps/api/` (тесты — `apps/api/tests/`).
